# AIGC Interactive Character Simulator Godot Client

这是当前前端主线，已经加入“出租屋 -> 街道 -> AI 伴侣商店 -> 回家互动”的基础剧情流程。开场先看剧情，再进入商店生成角色，最后回到出租屋开始互动。

## 当前功能

- 游戏风格主菜单
- 出租屋开场背景
- 弹出式剧情对话
- 街道过渡章节
- AI 伴侣商店背景
- 商店式伴侣挑选界面
- 沉浸式商店挑选模式
- 无图片 API 的占位伴侣档案
- 角色列表和角色资料
- 回家后开启 Chat UI
- 面对面沉浸对话模式
- 可隐藏主界面，只保留角色、背景、对白框和输入
- 日程系统：早上、下午、晚上
- 白天行动：打工、学习 AI 调参、逛街、买礼物
- FastAPI API 调用
- 模块化剧情 pack

## 打开方式

1. 安装 Godot 4.2 或更新版本。
2. 用 Godot 打开 `godot-client` 文件夹。
3. 运行主场景。
4. 确认 Backend 在运行，默认地址是 `http://127.0.0.1:8000`。

## 基础剧情流程

1. 出租屋：弹出对话介绍主角和目标。
2. 街道：显示出门前往商店的过渡对白。
3. AI 伴侣商店：开启角色创建和 API 配置。
4. 选择角色：创建或选择 AI 伴侣。
5. 回到出租屋：只播放短过场，不再打开工程式角色资料页。
6. 房间互动：直接进入全屏面对面模式，开始和生成的 AI 角色互动。
7. 面对面模式：隐藏菜单，对着角色直接说话。

## 日程系统

当前已经加入轻量日程循环：

- 一天分为早上、下午、晚上
- 早上和下午可以安排白天行动
- 打工：增加资金
- 学习 AI 调参：增加调参理解
- 逛街：增加一点关系进展
- 买礼物：消耗资金，增加关系进展
- 晚上可以回家进入面对面互动

如果已经选择了 AI 伴侣，部分白天行动会写入她的记忆，晚上对话时可以被后端带入上下文。

## 无图片 API 测试

当前商店页支持先登记“占位伴侣”：

- 不需要填写图片 API Key
- 不会等待图片生成
- 可以直接测试 DeepSeek / 文本对话 API
- 可以测试角色性格、背景、初始记忆和关系记忆

图片 API 只负责后续生成正式立绘和动作图，不再阻塞进入聊天。

如果点击登记后一直没有反应，客户端会在超时后提示后端没有响应。此时先确认 FastAPI Backend 正在运行，默认地址是：

```text
http://127.0.0.1:8000
```

## 商店挑选界面

AI 伴侣商店现在默认使用沉浸式挑选流程：

- 展示柜基础型号：温柔陪伴型、活泼好奇型、安静守护型、自定义空白型
- 性别选择
- 年龄限制：21-34 岁
- 画风选择：真人写实、二次元、国漫脸、半写实
- 外貌描述
- 占位预览

玩家正常路线会隐藏大部分后台界面，只看到商店背景、展示柜、店员对白和少量选择控件。点击“登记并带回家”后，游戏会先保存一个可聊天角色档案。之后再接入图片 API，就可以把这个档案升级成正式形象。

商店右上角的“后台”按钮会打开调试界面，方便开发时查看完整角色资料和接口状态。

## 恋爱模拟器方向

回到出租屋后，游戏会优先进入面对面沉浸对话模式。聊天页左侧仍然保留“房间里的她”的调试入口，点击：

```text
隐藏界面，面对面说话
```

会进入沉浸式对话界面，只保留出租屋背景、角色舞台、底部对白框和输入框，更接近恋爱模拟器体验。

## 剧情模块

基础剧情在：

```text
scripts/story/base_game_pack.gd
```

后续 DLC 可以新增自己的剧情 pack，按照 `StoryPackBase` 提供章节数据，再由主场景加载。每个章节可以独立配置：

- 背景图
- 标题
- 说话者
- 对话文本
- 是否显示游戏功能
- 章节结束后的按钮文字
- 进入哪个功能页面
